<h1 align="center">Codex Passport（便携控制面板）</h1>
<p align="center">为 FoloToy AI Passport（目标设备）制作的三键控制固件。</p>
<p align="center"><strong>使用桌面应用原生硬件功能直连，无需额外桥接软件。</strong></p>

本项目将设备变成便携蓝牙控制面板，通过 **ChatGPT Desktop（桌面应用）的原生 Codex Micro（硬件控制）功能**，用三个实体按钮选择智能体、发送命令和控制电脑麦克风。

不需要自定义电脑应用、插件、无线局域网、云端转发或接口密钥。**仍需安装兼容的桌面应用。** 这是独立的互操作实验，并非官方产品，也不是命令行工具的硬件配对功能。

## 功能

- 六个智能体按键，显示电脑同步的状态颜色。
- 快速模式、审批通过、审批拒绝、分支会话、麦克风和发送；审批操作有本地二次确认。
- 四向虚拟摇杆，以及旋钮转动、点击和长按。
- 三页非触摸界面，记住各页焦点，保留真实按下与松开时序。
- 本机侧边栏：关闭屏幕、调整亮度、重新配对和诊断信息。
- 加密蓝牙人机接口、配对绑定、断线重新广播及实际电量读取。

**麦克风按钮控制的是电脑麦克风。** 设备内置麦克风不会向电脑传输音频。板级接口无法测量充电状态时，会报告未知，而不是伪造结果。

## 硬件与环境

| 项目 | 要求 |
| --- | --- |
| 设备 | FoloToy AI Passport（目标设备），ESP32-C3（主控），8 MB 闪存，无外部内存 |
| 屏幕 | 240 × 320 竖屏，ST7789P3（显示控制器） |
| 按键 | 现有电阻分压网络上的 UP（上键）、DOWN（下键）、OK（确定键） |
| 编译 | ESP-IDF（开发框架）5.5.3，使用仓库依赖锁 |
| 电脑 | macOS（操作系统），兼容的桌面应用，已授予输入监控权限 |

不需要改接线、触摸屏或外置键盘。

## 操作

| 实体操作 | 功能 |
| --- | --- |
| 上键／下键短按 | 选择上一项／下一项 |
| 上键／下键长按至少 500 毫秒 | 上一页／下一页 |
| 确定键按下／松开 | 按下／松开当前虚拟控件 |
| 持续按住确定键 | 保持麦克风或旋钮点击的按下状态 |
| 快速点击两次确定键 | 原样发送两组事件，由电脑判断双击行为 |

页面按“智能体 → 命令 → 摇杆／旋钮”循环，各页分别记住选择位置。审批通过和拒绝需要在三秒内再次按下确定键，导航会取消确认。

选择摇杆／旋钮页最后一格 Settings（设置）打开侧边栏。关闭屏幕后，第一次按键只唤醒屏幕，不发送远端操作。重新配对需要二次确认，并在电脑端忽略原设备。

完整映射、协议和排查步骤见[使用指南](docs/codex-passport-guide.zh_CN.md)。

## 编译与测试

按[环境说明](docs/development/engineering/environment-setup.zh_CN.md)启用指定开发框架，在项目根目录执行：

```bash
idf.py build
./tools/validate.sh
```

完整验证包含仓库检查、主机测试、真实图形库渲染、固件编译、合并镜像及对应调试文件校验。仅检查源码和主机逻辑时执行：

```bash
./tools/validate.sh --static
```

验证后的完整镜像是 `build/FoloToy-AI-Passport-full.bin`（完整固件）。文件前缀保留上游名称，以兼容现有工具。对应调试文件和清单位于 `build/firmware/<full-image-sha256>/`（按镜像校验值命名的目录）。

`build/`（构建产物）、`managed_components/`（依赖缓存）、`dist/`（本机发布包）不提交。固件作为发布附件分发，并保留匹配的调试文件。测试、依赖锁、构建工具和硬件文档属于源码的一部分。

## 刷写与连接

使用发布附件中的已验证完整固件，或自行编译。**完整镜像刷入偏移为 `0x0`**，不能将单独的应用镜像刷到这个位置。将下方 PORT（串口占位符）替换为实际设备端口：

```bash
python -m esptool --chip esp32c3 --port PORT --baud 460800 \
  write_flash --flash_mode dio --flash_size 8MB --flash_freq 80m \
  0x0 build/FoloToy-AI-Passport-full.bin
idf.py -p PORT monitor
```

完整镜像可能重置设置和配对信息，不需要整片擦除。编译与验证命令不会刷写设备。

1. 在可信环境下，从电脑蓝牙设置中配对 Codex Micro（设备广播名称）。
2. 打开桌面应用，授予“输入监控”权限。
3. 进入设置中的硬件控制页面，检查设备识别情况。
4. 检查通知订阅和实际按键响应；蓝牙已连接不等于应用功能验收通过。

配对使用加密安全连接，但没有配对码校验。[实机验收清单](docs/codex-passport-guide.zh_CN.md)包含全部控件、重连和诊断检查。
